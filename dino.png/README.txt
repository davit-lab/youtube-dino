Character Animation PNG Pack
============================

Extracted from the supplied character reference image.

Animations:
- idle: 8 frames
- walk: 8 frames
- run: 8 frames
- jump: 7 frames
- shoot: 7 frames

All frames are individual transparent-background PNG files, ready to import/use from a VS Code HTML5 Canvas game.

Recommended JS usage:
  const img = new Image();
  img.src = './assets/character/idle/idle_01.png';

Folder names and frame names are stable and zero-padded for easy animation loading.
